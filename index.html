¿Qué se puede observar?

La tecla, el código físico, si se mantiene pulsada y el intervalo entre pulsaciones. Un evento input también detecta cambios realizados por teclados virtuales. Esta demo registra la longitud del texto, no su contenido completo.

Incluso antes de tu primer clic

Tu navegador ya trae contexto.

Lecturas al abrir la página. El navegador puede limitar o modificar estos valores por privacidad.

Hay límites a lo que una página sabe.

Tu nombre, tus contraseñas, el contenido de otras pestañas y tu historial completo no aparecen automáticamente en estos eventos.

Otros datos necesitan permiso.

La cámara, el micrófono y la ubicación precisa normalmente requieren autorización. Aquí no los solicitamos.

Conectarse también deja un rastro.

Un servidor recibe información de la conexión, como la IP. Esta demo no consulta tu IP. El alojamiento puede mantener sus propios registros técnicos.

Observar no es lo mismo que comprender

Del gesto a una posible interpretación.

01 / OBSERVAR

«Pasó por aquí»

Posición, instante, clic y elemento visitado. JavaScript escucha eventos y lee sus propiedades.

02 / AGREGAR

«Aquí se detiene más»

Muchos eventos pueden formar mapas de calor, recorridos y estadísticas de uso. Aquí solo ves tu sesión.

03 / INFERIR

«Quizá le interesa»

Se pueden formular hipótesis sobre interés o dificultad, mejorar interfaces o personalizar contenido. Una hipótesis puede equivocarse.

¿Sucede en sitios como Amazon?

Su aviso de privacidad enumera información de interacción como scroll, clics y paso del mouse sobre elementos. Esto no significa que cada sitio registre todo, ni nos dice cómo se procesa cada evento.

document.addEventListener('pointermove', (evento) => {
  const dato = {
    tipo: evento.type,
    x: evento.clientX,
    y: evento.clientY,
    tiempo: performance.now()
  };
  // Ahora puedes mostrarlo, contarlo o guardarlo.
});

Escuchar un evento no lo transmite automáticamente. Enviarlo a una empresa requiere código adicional. Esta demo no incorpora analítica ni transmisión de tus eventos.
